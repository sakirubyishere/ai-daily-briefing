算 力 硬 件

内存"超级周期"再预警：2027年产能基本售罄，HBM 挤占通用 DRAM，四季度起单季涨价或达三至四成

发布时间：2026-11-03（北京时间）　|　来源：快科技／腾讯新闻　|　阅读原文 ↗

内存模组厂商十铨于11月2日召开业绩说明会，直言本轮内存景气周期与以往截然不同：核心动因是产业结构变化，原厂与模组厂同步走向寡头格局，价格已连续上涨一年，短期看不到反转信号。十铨判断，真正的缺货最严峻阶段尚未到来，今年四季度到明年二季度末将是供货最紧张的窗口，不排除"有钱也拿不到货"。价格方面，四季度至明年一季度将继续上行，部分产品单季涨幅达30%—40%，AI算力设备进一步拉动LPDDR5X需求。目前SK海力士、美光等大厂2027年产能已基本售罄，同时把产能大规模转向利润更高的HBM，通用DRAM供给被系统性压缩。机构测算显示，HBM占DRAM总产能比重已从2024年的12.3%升至2026年的20.8%，2027年料达22.5%；SK海力士计划2026年全面停产DDR4，美光仅保留车用与工业定制产能，中低端手机与PC正承受成本与需求的双向挤压。

▍价值点分析

存储正取代GPU成为AI算力扩张最刚性的瓶颈之一，"近四分之一晶圆投给HBM、却只产出约十一分之一容量"的结构性错配，意味着涨价周期比以往更长。对我国而言，这是双重压力：一方面，HBM与高端DRAM被出口管制与寡头产能双重锁定，国产AI芯片的"卡脖子"环节从制程前移到内存；另一方面，通用DRAM涨价直接抬升国产服务器整机与消费电子成本，压缩利润空间。应对之道有二：一是加快HBM3E及国产DRAM扩产的工程化落地，把有限产能优先配置给训练/推理集群；二是通过长协锁价、库存前置与架构侧降内存占用（如稀疏计算、W4A4量化）对冲成本。今日美团LongCat-2.5在国产80GB单卡上跑通万亿参数训练，恰是"以工程换硬件"的现实样本。

高通第一代 HBC（高带宽计算）架构完成硬件验证，3D 近存计算绕开 HBM 与 CoWoS

发布时间：2026-11-03（北京时间）　|　来源：科创板日报　|　阅读原文 ↗

据《科创板日报》11月3日报道，高通宣布其第一代HBC（High Bandwidth Compute，高带宽计算）技术已在美国圣迭戈实验室完成硬件验证，验证了完整的读写能力与近存计算（Near-Memory Computing）能力。HBC是高通2026年6月在纽约投资者日上发布的专用近存计算架构，通过TSV硅通孔实现3D堆叠，把专用近内存加速器直接叠在LPDDR存储堆栈下方，计算与内存的物理距离压缩到几微米，直指AI推理的"存储墙"与数据搬运瓶颈。其关键设计是"分离式3D堆叠"：整颗芯片拆为主SoC与HBC堆栈两部分，二者经标准2D有机基板互连，从而绕开昂贵的硅中介层与CoWoS封装，系统性降低成本。按路线图，HBC Gen1将搭载于AI250加速器，计划2027年上半年出样；Gen2配套AI300，预计2028年推出。微软Azure已确认将部署HBC芯片，高通ASIC业务已启动晶圆生产，预计2026年12月季度开始产生收入。

▍价值点分析

HBC的技术意义在于"换道"：当HBM供给被三家原厂垄断且价格失控、CoWoS产能长期紧张时，用LPDDR 3D堆叠+成熟有机基板实现近存计算，实际上是把竞争维度从"抢HBM"转向"改架构"。这与我国东方算芯"上下两层内存紧贴中间计算芯片"、天数智芯144卡超节点等路线在同一逻辑上——不依赖最先进制程与最贵封装，靠体系设计补硬件差距。需要警惕的是，高通一旦在2027年把HBC推入Azure等超大规模集群，等于为美方提供了一条"HBM之外的第二条算力供给曲线"，削弱我国以HBM管制为杠杆的反制效果，也会在下游推理市场形成新的专利与生态壁垒。国内应加快近存/存算一体架构的标准与IP布局，避免在新赛道再次被动跟随。

台积电或接手 Terafab 建厂与运营，马斯克立场明显松动，双方准备重启谈判

发布时间：2026-11-02 22:21（北京时间）　|　来源：DIGITIMES／半导体行业圈　|　阅读原文 ↗

据DIGITIMES报道，马斯克对台积电参与Terafab晶圆厂项目的态度已明显软化，双方正准备重启谈判。此前马斯克坚持由自家企业独立建设、运营这座晶圆厂，目前该立场已经松动，供应链消息称谈判方向转向由台积电承担建厂与运营的主要责任，股权结构与投资安排仍在磋商。回溯时间线：10月3日马斯克在X平台仅确认双方处于讨论阶段；10月7日有网友称最可能方案是台积电持有并运营该厂，马斯克直接否认"这座工厂由我们来建、由我们来运营"；10月15日台积电第三季度法说会上，董事长兼总裁魏哲家明确前提——合作模式可以多种，但只要台积电参与，晶圆厂必须由台积电运营。同日英特尔CEO陈立武向彭博社确认英特尔仍会参与Terafab。路透社分析，若台积电深度入局，可能挤压英特尔在项目内的空间；马斯克原计划依托英特尔下一代14A工艺在Terafab生产芯片，特斯拉将是14A的首个大客户。

▍价值点分析

Terafab的归属之争，本质是"美国本土先进产能由谁定义标准"的问题。若台积电最终拿下运营权，意味着美方把最优质的代工组织能力进一步内化到本土，与英特尔14A形成"双保险"，对我国的间接影响有三：其一，先进制程与封装的本土化闭环加速，长期削弱我国通过全球供应链获取二手产能的空间；其二，特斯拉这类"算力+整车+机器人"垂直整合客户被锁定在美系工艺上，形成从芯片到终端的排他生态；其三，台积电的产能与人力将被进一步分流，其在大陆的成熟制程布局可能更趋保守。反过来看，这也暴露了美国本土建厂的组织能力短板——连马斯克都要回头找台积电，说明"制造回流"并非砸钱即可解决。我国应抓住窗口，把成熟制程的产能、良率与成本优势做到极致，同时加快设备与零部件的国产替代。

技 术 进 展

GPT-6.2 "Astra" 灰度上线，Claude Mythos 5.5 同日曝光

发布时间：2026-11-03（北京时间）　|　来源：量子位／AI技术日报　|　阅读原文 ↗

11月刚开局，两家头部实验室的新模型即正面相撞。据量子位报道，部分ChatGPT用户的模型列表中已出现GPT-6.2-Astra且确实可用：有用户约20%的请求被路由至6.2，也有用户100%命中，但基本需要每月500美元的Pro套餐才能被灰度到。Claude一侧，Mythos 5.5曾短暂出现在官网前端代码中，数小时后被移除，据称是包含生物学研究与网络安全能力的版本。与此同时，HuggingFace上出现了一个声称是Mythos泄露权重的仓库，虽然大概率是伪造，已有5000多次下载。从社区流传的"鹈鹕骑车"对比样本看，Claude更偏艺术风格，GPT更注重物理效果。业内普遍判断，这类"前端代码泄露＋小比例灰度"通常意味着正式发布已进入倒计时，两家在年底前完成一轮旗舰迭代的概率很高。

▍价值点分析

这次撞期透露出两个信号。第一，旗舰模型的迭代节奏已压缩到半年以内，且开始按"专业能力域"分包——Mythos 5.5被指包含生物研究与网安专项，说明前沿实验室正把通用模型切成面向高价值行业的"能力切片"，这比单纯刷榜更具商业杀伤力。第二，灰度与泄露成为低成本的市场预热手段，模型发布本身已高度产品化。对我国而言，压力不在参数规模，而在"能力切片"的深度：生物、网络安全、代码审计这类高门槛领域，需要长期积累的专业数据与评测体系，短期难以靠开源权重追平。同时也提示安全风险——伪造权重仓库已获数千次下载，供应链投毒的门槛正在降低，国内模型分发平台应尽快建立权重签名与来源验证机制。

Anthropic 开放 Messages API "message threads"，长任务 Agent 不再重发整段对话

发布时间：2026-11-03（北京时间）　|　来源：Anthropic／AI技术日报　|　阅读原文 ↗

Anthropic 在 Messages API 中开放 message threads 公开测试，核心思路是"对话只发一次"。此前开发者构建长跑型 Agent 时，每一轮调用都需要把完整历史对话重新提交给模型，上下文越长，Token 成本与延迟越高，且极易触发上下文窗口上限。message threads 把多轮交互组织为可持续引用的线程对象，客户端只需传入增量内容，服务端负责维护上下文状态，相当于把"上下文管理"从应用层上移到 API 层。这一改动对连续运行数小时乃至数天的自动化 Agent 尤为关键——此前业界普遍采用摘要压缩、滑动窗口等"打补丁"方案，代价是信息丢失与行为漂移。Anthropic 近期在 Agent 工具链上动作密集，Claude Code、Claude Cowork 等产品已把长时任务作为主打场景，此次 API 层改造被视为其 Agent 战略的基础设施补课。

▍价值点分析

长上下文重复传输是当前 Agent 落地最被低估的成本黑洞：一个持续运行的工作流，Token 消耗往往随轮次呈平方级增长。Anthropic 把状态维护收归 API 层，等于把"上下文工程"变成平台能力，这会显著拉高其企业客户的迁移成本，形成新的锁定点。对国内厂商而言，这是一次明确的技术路线提示——单纯比拼上下文窗口长度已无意义，真正要比的是"状态管理＋增量推理"的工程效率。DeepSeek、通义、混元等在国产算力上普遍面临显存偏小的约束，恰恰最需要这类机制：把长上下文的存储与调度从单卡显存转移到服务端与超节点互联，可以用架构设计换硬件短板。建议国内云厂商在 API 层尽快跟进线程化上下文标准，避免开发者生态被海外接口形态先行定义。

美团发布 LongCat-2.5：1.6 万亿参数原生多模态，全程国产算力训练，多项智能体基准登顶

发布时间：2026-11-02（北京时间）　|　来源：新华网　|　阅读原文 ↗

11月2日，美团发布新一代大模型LongCat-2.5，这是一款面向长程智能体任务的原生多模态模型，总参数1.6万亿、每Token激活约480亿，训练全程由国产算力完成，是目前依托国产算力完成的最大规模训练任务。相较6月发布的LongCat-2.0，新模型强化了原生视觉理解与智能体编程：视觉信号被编码为多层级离散Token，使主干网络以统一Token形式处理图文输入，可支撑交互网页、3D展示页面等任务；智能体侧采用大规模长程强化学习，提升端到端工程能力。评测覆盖9项国际主流基准，AutomationBench得51.8分（Claude-Opus-5为50.3）、BrowseComp得91.9分居首、3DCodeBench得55.4分小幅领先，Terminal Bench v4.0得38.5分超过GPT-5.6-Sol的37.3分，整体成绩介于Claude Opus 4.8与Opus 5之间。工程上，团队针对国产单卡80GB显存优化超节点并行与FSDP双重分片，长序列SFT单卡吞吐提升86%；推理侧W4A4量化使Prefill／Decode吞吐分别提升43.3%与42.77%，首次输出等待缩短约16%。

▍价值点分析

这条新闻的真正分量不在参数，而在"闭环"二字：1.6万亿总参数、最长1M Token序列、数万亿Token训练量，全部跑在国产算力上，说明国产芯片＋国产框架已具备支撑前沿规模训练的系统能力，这对"算力被卡就训不出好模型"的论断是一次实证反驳。更值得关注的是其"以工程换硬件"的方法论——针对国产卡显存小、互联弱的短板，用超节点内高速互联承载主要通信、用W4A4把权重与激活压到4比特，把硬件劣势转化为调度与量化问题。这条路径对我国产业安全具有直接价值：即便先进制程与HBM持续受限，仍可通过软硬协同维持模型代际不落后。风险在于，此类模型的训练成本仍高度依赖单一大客户的自有负载，商业化边界取决于能否进入真实工作流，美团选择嵌入商家经营分析与智能体编程，是一条务实的差异化路线。

腾讯混元发布 AI 科研系统 Hyra 2.0：从"用 AI 解题"转向"让 Agent 造科研工具"

发布时间：2026-11-02（北京时间）　|　来源：腾讯混元／行业早报　|　阅读原文 ↗

11月2日，腾讯混元发布AI科研系统Hyra 2.0，研发重点出现明显转向：从此前"直接用AI攻克科学难题"，转为让通用Agent深度参与科学模型、研究工作流及软件工具的研发。这一调整对应着AI for Science领域近一年的路线反思——早期尝试多用大模型直接预测蛋白质结构、材料性能或求解方程，受限于领域数据稀缺与可验证性不足，成果难以复现；而科研活动的真实瓶颈往往在工具链：代码环境搭建、实验参数扫描、数据清洗与可视化、论文级图表的批量生成，这些环节高度重复且极易出错，正是Agent擅长之处。Hyra 2.0的定位因此更像"科研基础设施的操作系统"，让Agent承担工具生产与流程编排，人类研究者专注于问题定义与结果判断。腾讯方面尚未披露具体评测数据与开放范围。

▍价值点分析

"AI for Science"正在从"替代科学家思考"退回到"替代科学家动手"，这个转向对我国的科研体系更有现实意义。我国科研软件长期依赖进口，Matlab、COMSOL、各类仿真与实验控制软件构成隐性依赖，而Agent驱动的工具生成能力，恰恰提供了绕开传统商业软件授权壁垒的可能——用自然语言描述需求，由Agent生成脚本、搭建流程、批量产出结果，相当于把"软件采购"变成"能力生成"。这与求是网同期强调的"突破工业软件等关键核心技术"方向一致。需要清醒的是，科研场景对可复现性与数值正确性的要求远高于通用应用，Agent生成的工具若缺乏严格验证，可能制造大量"看起来合理"的错误结论。国内应同步建设AI科研工具的验证基准与审计规范，避免效率提升以科研诚信为代价。

11月2日，Anthropic PBC披露截至9月30日的第三季度业绩并更新招股书：季度营收169.56亿美元，较上年同期的13.82亿美元增长约11倍；调整后营业利润24.63亿美元，高于第二季度的22.35亿美元；但受股权激励等项目影响，净亏损达233亿美元，运营费用升至175亿美元、同比增292%。2026年前9个月营收332.42亿美元、运营亏损12.6亿美元。同一份文件披露，公司已敲定总额约8950亿美元的承诺支出，绝大部分投向算力与基础设施。此前10月26日Anthropic已向美国SEC递交IPO申请，拟以"ANT"为代码登陆纳斯达克，预计11月16日当周上市，目标募资规模力争达到甚至超过SpaceX此前862亿美元的水平；投资者日讨论的估值约1.5万亿美元，低于此前预期的2万亿美元。公司还计划在IPO中向日本投资者筹集至多35亿美元，由瑞穗证券负责日本部分。2026年5月其H轮融资650亿美元，估值9650亿美元。

▍价值点分析

这份招股书第一次把大模型商业化的真实账本摊开：收入曲线陡峭（年化近680亿美元），但成本曲线同样陡峭——8950亿美元承诺支出相当于把未来数年的算力账单提前锁定，其规模已接近一个中等国家的GDP。这解释了为何"AI泡沫论"与"AI军备竞赛论"同时成立：需求是真的，但利润被上游算力、电力与人才吃掉。对我国有三点提示。其一，算力承诺的期限结构意味着HBM、先进封装、电力的紧缺将至少延续到2029年，国产替代的窗口期比预期更长也更紧迫。其二，Anthropic选择在感恩节前抢跑上市、并引入日本资本，说明头部模型公司已进入"用公开市场为算力扩张融资"的阶段，我国AI企业应加快多元化融资渠道建设。其三，1.5万亿美元估值对应百亿美元级亏损，一旦资本市场风险偏好逆转，全球AI投资节奏将剧烈波动，需防范对国内供应链订单的传导冲击。

墨芯人工智能完成近 10 亿元 C+ 轮融资，两轮累计近 20 亿，稀疏推理芯片加速铺开

发布时间：2026-11-03（北京时间）　|　来源：投资界　|　阅读原文 ↗

11月3日，墨芯人工智能科技（深圳）有限公司宣布完成近10亿元人民币C+轮融资。本轮由仁爱资本、海棠基金、东恒石油及其他国内一线产业方，以及比丘资本、派拉资本、中财资本等国资及财投机构共同参与。距上一轮近10亿元融资落地仅5个月，两轮累计融资近20亿元。募集资金将投向稀疏专用推理芯片的全栈升级，重点开展下一代芯片预研，并推进稀疏计算产学研联盟建设。墨芯自成立起锚定稀疏计算路线，通过"算法—软件—硬件"协同设计，把稀疏化从论文指标变成可部署产品。商业化方面，2026年第三季度营收实现数倍增长；基于自研芯片的推理集群已在西北、西南、华东、华北四大片区铺开，并与头部电信运营商建立合作，将稀疏计算推理方案纳入其算力服务体系。产品侧，新一代板卡SP200将在年底前问世；升级版软件栈SECA（Sparse-native Efficient Computing Architecture，稀疏原生高效计算架构）即将发布，强化对大模型推理部署与集群运维的支持。

▍价值点分析

稀疏计算是国产算力"绕过制程劣势"最现实的技术杠杆之一：在同等工艺与显存条件下，通过结构化稀疏把有效算力密度提升数倍，正面回应了国产卡"算力账面不低、实测效率打折"的痛点。墨芯五个月内连获两轮近10亿融资、且产业方与国资同时入场，说明资本对该路线的判断已从"概念验证"转向"规模交付"。更值得注意的是其与电信运营商的绑定——把稀疏推理方案纳入运营商算力服务体系，意味着国产芯片首次以"标准化算力商品"而非"项目定制"的方式进入国家算力网络，这对构建自主可控的算力供给体系具有示范意义。风险在于，稀疏化对模型结构的适配有前提条件，若前沿模型架构快速演进（如MoE、线性注意力），专用推理芯片可能面临适配滞后；国内厂商需在专用化与通用性之间保持平衡，并尽早参与推理接口与算子标准的制定。

Marvell 以 1150 亿美元全股票收购 Lumentum，合并瞄准 5500 亿美元 AI 连接市场

发布时间：2026-11-02 20:37（北京时间）　|　来源：Marvell／界面新闻／财联社　|　阅读原文 ↗

11月2日，Marvell Technology与光通信设备制造商Lumentum宣布达成最终协议，Marvell将通过全股票交易收购Lumentum。交易隐含企业价值约1150亿美元，溢价约23.9%；交易完成后，Lumentum股东将持有合并后公司约33%的股份。双方表示，合并旨在整合光互连技术，打造覆盖"从芯片到数据中心"的AI连接方案，瞄准规模约5500亿美元的AI连接市场。这桩交易的结构颇具标志性：以全股票方式完成、且被收购方股东保留三分之一股权，实质是两家公司在AI互联赛道上的对等合并，而非传统意义上的吞并。背景是AI集群规模从万卡向十万卡演进后，节点间与集群间的带宽需求呈指数上升，光互连（含CPO共封装光学、硅光模块、光引擎）正取代铜互连成为系统瓶颈。此前英伟达已展示下一代CPO方案OOI，将光引擎直接封装在硅中介层上，产业链上下游的重组随之加速。

▍价值点分析

当训练集群的瓶颈从晶体管转向"互联带宽"，光通信就从配角变成主战场。Marvell吞下Lumentum，本质是把电芯片（DSP、SerDes、交换）与光芯片（激光器、光引擎）合并到同一张资产负债表上，形成"光电一体"的议价能力——这正是英伟达CPO路线最需要的配套，也意味着未来AI集群的光互连标准将更多由美系厂商联合定义。对我国而言，光模块是我国少数在全球具备份额优势的环节（中际旭创、新易盛等），但上游光芯片、高速DSP仍高度依赖进口。此次整合后，我国光模块厂商可能面临"客户变对手"的局面：既要在美系主导的标准下供货，又要应对合并方自供比例上升带来的份额挤压。当务之急是加快25G以上高速激光器芯片、硅光工艺与CPO封装设备的国产化，并在标准制定层面争取话语权，避免在互联环节重演"整机强、器件弱"的被动格局。

沙特阿美 26 亿美元入股 AI 公司 Humain 49% 股权，石油资本加码算力版图

11月2日，沙特阿美宣布以26亿美元收购AI公司Humain 49%的股权。Humain承担着推动沙特成为全球AI产业目的地的国家任务，业务覆盖数据中心建设、算力供给与本地化模型训练。此次入股使沙特阿美从"能源供应商"进一步转变为"AI基础设施股东"：数据中心最稀缺的资源是电力，而沙特阿美兼具发电能力、土地与资本，把石油美元直接转换为算力资产，是一条闭环逻辑。这也是海湾主权资本近两年布局AI的延续——阿联酋、卡塔尔此前已通过主权基金与美方芯片厂商达成算力合作，美国亦在2026年7月放宽对阿联酋的出口管制，将其升级为"最受信赖的防务与技术合作伙伴"之一。对全球算力格局而言，中东正成为继美国、中国之后的第三个大规模集群落地区域，其低成本电力与宽松监管构成独特吸引力。

▍价值点分析

石油资本入股AI基础设施，反映的是全球算力版图的"能源化"重构：未来决定集群落在哪里，不再只看人才与产业链，而看谁能提供稳定的低价电力与宽松的审批环境。这对我国是复合影响。一方面，中东算力枢纽的崛起为中国AI企业提供了新的出海通道——沙特、阿联酋在智慧城市、阿拉伯语大模型、行业应用上需求旺盛，且对我国技术与设备接受度较高，是绕过欧美市场壁垒的现实突破口。另一方面，美国通过放宽对阿联酋的芯片出口管制，正把中东纳入自身技术生态，若海湾国家的算力底座全部建立在美系芯片与框架之上，中国方案进入的门槛将显著抬高。建议国内厂商加快以"整体解决方案＋本地化运营"方式参与中东项目，同时警惕在高端芯片转口贸易上的合规风险。

美国 20 个社区同日就暂停／禁止数据中心建设表决，AI 基建首次被地方政治直接定价

发布时间：2026-11-03（北京时间）　|　来源：POLITICO／我的钢铁网　|　阅读原文 ↗

据POLITICO报道，当地时间周二，美国将有20个社区就"暂停或禁止当地数据中心建设"的倡议进行表决，其中13个社区位于共和党主导的选区。两党游说机构Monument Advocacy负责人兼首席AI官Joseph Hoefer表示，"一个人完全可以支持美国在AI领域保持领先，同时对自己所在社区应该以何种方式开发建设持有保留意见"，因此科技企业很难仅凭政党归属判断一个社区的态度。近期民调显示，美国选民整体上更倾向反对"支持数据中心建设的候选人"，且反对情绪跨越党派：36%的共和党选民与65%的民主党选民表示，若在住所3英里（约4.8公里）内建设数据中心将持反对或强烈反对态度。全美已有超过300项地方性暂停令。新墨西哥州甲骨文1650亿美元"木星项目"因居民反对、审批受阻及电力供应挑战面临延期；得州州长已下令开展审计导致并网项目额外延误数月；纽约州一项暂停大型设施环境许可审批的行政命令，已导致近1GW数据中心建设延误。

▍价值点分析

这是AI基建第一次被"一人一票"直接定价。摩根士丹利预计微软、亚马逊、Alphabet、Meta等超大规模企业2027年资本支出将超1万亿美元，而这笔钱能否落地，正在取决于电价、水权、噪音与地方选举——技术问题彻底政治化。对我国有三重启示。其一，美国算力扩张的"摩擦成本"正在上升，项目延期与融资重算将削弱其算力供给的确定性，为我国缩小算力差距提供时间窗口。其二，我国"东数西算"的集中审批与统一调度机制，在这一维度上具备制度效率优势，应加快把西部绿电资源转化为可调度的智能算力，形成"低成本电力＋高效审批"的组合优势。其三，也要警惕国内出现类似的邻避效应——随着单体集群规模迈向GW级，地方对电价、水耗与土地的敏感度将同步上升，需提前建立社区沟通、成本分担与绿电配套机制。

广电总局：10 月清理"AI 魔改"违规视频 1.1 万余条，处置违规账号 30 余个

发布时间：2026-11-02（北京时间）　|　来源：国家广播电视总局／行业早报　|　阅读原文 ↗

国家广播电视总局11月2日披露，部分重点网络视听平台在10月共清理"AI魔改"违规视频11000余条，处置违规账号30余个。所谓"AI魔改"，指利用生成式视频或图像模型，对经典影视剧、新闻画面、公众人物形象进行篡改、拼接或再生成，制造荒诞、低俗甚至虚假内容以博取流量。此类内容在近一年随视频生成模型能力跃升而快速泛滥：过去需要专业团队与昂贵设备才能完成的镜头替换，如今一段提示词即可生成，且逼真度足以误导普通观众。广电总局此次行动延续了生成式AI内容治理的常态化思路——平台承担审核与标识责任，违规内容与账号同步处置。业内普遍认为，随着Seedance、可灵、Wan等视频模型进入商用，AI生成内容的标识制度、侵权认定与平台责任划分将成为下一阶段监管重点。

▍价值点分析

治理"AI魔改"的意义不止于内容秩序，更关乎我国视频生成产业的国际竞争力。当前国产视频模型（可灵、Seedance、Wan等）在生成质量上已进入全球第一梯队，但版权与合规风险是出海的最大障碍：影视IP篡改、公众人物换脸一旦规模化，平台将同时面临侵权诉讼与监管处罚。此次以"清理＋处置账号"为主的执法方式，实际上是在为产业划定红线——模型能力可以强，但内容生产必须可追溯、可标识、可追责。建议关注两个落地环节：一是隐式水印与内容凭证（C2PA类标准）在国内平台的部署进度，这决定跨境传播时的责任认定；二是训练数据中影视版权的授权机制，若不能建立合法的素材供应链，国产视频模型在海外市场将持续遭遇下架与索赔风险。

土耳其对谷歌 AI 概览与 AI 模式启动反垄断调查，聚焦新闻出版商流量与内容授权

发布时间：2026-11-02（北京时间）　|　来源：土耳其竞争管理局／界面新闻　|　阅读原文 ↗

11月2日，土耳其竞争管理局宣布对谷歌的AI概览（AI Overviews）与AI模式（AI Mode）功能启动反垄断调查，重点审查相关服务是否损害新闻出版商及其他内容创作者的利益，包括导致其网站流量下降、设置不公平的内容使用条款等。该机构同时要求谷歌确保新闻内容使用条款不构成歧视、反映内容的经济价值，并允许出版商自主决定是否授权相关AI服务使用其内容，且不影响其在谷歌其他服务中的展示和索引。这是继欧盟、美国之后，又一個监管辖区把"生成式搜索对内容生态的挤压"作为独立反垄断议题处理。其核心争议在于：当搜索引擎直接用AI摘要回答用户提问、不再导流至原网站，内容生产者的流量与广告收入被结构性剥夺，而模型的训练与生成又建立在他人内容之上，形成"使用—补偿"的断裂。

▍价值点分析

土耳其此举把一个全球性难题推上台面：AI搜索时代，内容的价值如何被计量与分配。对我国的直接意义在于，国内AI搜索（百度AI搜索、夸克、秘塔、微信AI搜索等）同样面临"摘要替代点击"的冲击，若缺乏事前规则，将重演传统媒体被平台化流量挤压的路径，最终削弱中文高质量语料的供给——而语料恰恰是国产大模型最稀缺的战略资源。建议在《人工智能生成合成内容标识办法》等既有框架上，进一步探索"内容授权＋收益分成"的机制设计，把新闻、学术、专业数据库等高质量中文语料纳入可交易的授权体系。这既是保护内容生产者，也是为我国模型训练建立可持续的、合法的数据供给链，避免长期依赖爬取带来的合规隐患。

韩国 2027 国防预算首破 70 万亿韩元，明确以 AI、机器人、无人机推动"智能化精锐军队"转型

发布时间：2026-11-03 08:56（北京时间）　|　来源：环球时报／韩联社　|　阅读原文 ↗
