AMD 交出史上最强季报：数据中心收入近乎翻倍，2027 年营收增速指引超 80%

发布时间：2026-11-04 06:30（北京时间）　|　来源：财联社　|　阅读原文 ↗

AMD 于美股11月3日盘后发布2026财年三季度财报并召开电话会。公司数据中心营收同比近乎翻倍，MI455X 与 Helios 机架本季度正式出货，Anthropic、Meta、微软、OpenAI、甲骨文等头部客户已上线部署；新一代 Venice EPYC 平台订单数量较上代 Turin 提升20%，并推出面向智能体负载的 Helion 交钥匙机架方案。公司同时把2027年营收增长目标上调至超过80%，是此前长期目标的两倍以上，并预计2027年末数据中心业务占总营收逾80%。苏姿丰称三季度只是"爬坡的最开始"。AMD 还宣布收购 Taalas 与 World Labs，补齐低延迟推理芯片与空间智能能力，李飞飞将出任首席科学家。风险方面，晶圆、基板、HBM 与先进封装产能构成增长上限。

▍价值点分析

这份财报最值得我国产业界注意的不是数字，而是"供应链锁定"能力。同在存储紧缺背景下，英特尔因拿不到原材料导致四季度指引暴跌近29%，AMD 却因提前锁定晶圆、基板、封装与内存而加速——说明 AI 时代的竞争已从单卡性能前移到"谁能把整条供应链签下来"。对我国而言，这意味着国产 GPU 若只解决芯片设计而无 HBM、先进封装、基板的稳定供给，产能天花板仍握在他人手里。AMD 收购低延迟推理芯片团队也提示：推理侧的单位 token 成本正在成为主战场，而这恰是国产算力最现实的突破口。

三星得州二厂将为英伟达与 AMD 生产 HBM 基础裸片，本月正式动工

发布时间：2026-11-03 20:00（北京时间）　|　来源：同花顺财经　|　阅读原文 ↗

据同花顺财经11月3日报道，三星电子将利用其位于美国得克萨斯州的第二座晶圆代工厂，为英伟达与 AMD 生产高带宽内存（HBM）芯片的基础裸片（base die），该工厂预计本月正式动工。此举意味着 HBM 供应链正向"美国本土制造"进一步聚拢。同一交易日，苹果 CEO 特努斯在财报会上坦言内存价格上涨正拖累新一季毛利率，并预计未来内存成本更高。此外，马斯克在 Terafab 芯片工厂如何与台积电合作的问题上立场软化，双方正准备重新谈判，台积电或将承担晶圆厂建设与运营的主要责任；Anthropic 表示力争2026年底算力规模超过3.5吉瓦、明年翻倍。

▍价值点分析

HBM 基础裸片是 HBM 堆栈中承担逻辑与控制功能的关键一层，此前主要由存储厂自有产线或台积电代工。三星把这道工序搬到得州，既是响应美国本土化要求，也是在为"AI 内存—算力"闭环争夺政策红利。对我国影响有两层：一是 HBM 供应进一步被地缘政治切割，国产算力卡的显存来源更依赖国产 HBM 的突破；二是基础裸片多采用先进逻辑工艺，若未来被纳入出口管制清单，将形成新的"卡点"。国内存储与代工的协同（如长鑫与中芯的工艺配合）需加快裸片层的自主方案，否则算力再强也会被显存带宽锁死。

沐曦股份获世界互联网大会"杰出贡献奖"，曦云 C600 依托全国产供应链量产

发布时间：2026-11-03 15:00（北京时间）　|　来源：浙江省工商业联合会　|　阅读原文 ↗

11月3日，2026年世界互联网大会乌镇峰会开幕。开幕式上，沐曦股份凭借在高性能通用 GPU 领域的自主创新、全栈产品布局及生态建设成果，获大会"杰出贡献奖"（成长潜力类）。大会期间，曦思 N300 与曦云 C600 两款 GPU 联袂展出。曦云 C600 基于全国产供应链打造，面向大模型训练与推理，已于上半年首批通过国家《安全可靠测评》并实现量产销售；7月 WAIC 发布的曦景 S 系列超节点具备高算力密度、高互连带宽特性，支持横向扩展至万卡集群。软件侧自研 MXMACA 栈已支持40余种 AI 框架、1000多款模型，完成超6000个热门开源项目运行测试。公司2026年前三季度营收28.24亿元，同比增长128.45%。

▍价值点分析

沐曦的意义不在单卡跑分，而在"全国产供应链＋量产销售＋通过安全可靠测评"这条完整闭环被打通——这是国产 GPU 从样机走向可采购商品的必要条件。前三季度营收增长128%，说明政企与智算中心订单正在真实落地，而非停留在送样阶段。但要清醒：MXMACA 兼容 CUDA 生态带来迁移便利的同时，也意味着短期内仍难摆脱"跟随式兼容"的路径依赖。下一步的关键是从"能替代"转向"定义新负载"——尤其在 MoE 推理、超节点互联这些国产厂商已有工程经验的场景上建立标准话语权，否则永远只能做别人的影子。

Kimi K3.1 Pro 开放全部权重：2.8 万亿参数 MoE，AA 智能指数 55 分位列全球第四

发布时间：2026-11-04 08:00（北京时间）　|　来源：月之暗面官方公告 / CSDN　|　阅读原文 ↗

11月4日，月之暗面按计划开放 Kimi K3.1 Pro 的完整模型权重。该模型采用2.8万亿参数 MoE 架构，每 token 激活约1040亿参数，支持100万 token 上下文，主打编程、3D 创作与金融研究。独立评测机构 Artificial Analysis 给出的智能指数为55分，位列全球第四，仅次于 Claude Opus 5.5（58分）、Claude Sonnet 5.5 与 Muse Wonder Full（均56分）；开源阵营与闭源前沿的差距由12分缩至3分，成为该指数上排名最高的开放权重模型。Agent 能力提升更明显：Terminal-Bench 4.0 由13%跃升至67%，AutomationBench-AA 从58%升至73%。值得注意的是，月之暗面在中训与强化学习阶段主动移除了网络攻防数据，内部基准 exploit 通过率由90.5%降至81.0%。

▍价值点分析

完整权重开放对国内金融、医疗等数据不能出域的行业是直接利好——可本地部署、审计、微调，这是 API 模式无法替代的价值。更值得关注的是"主动裁剪网安能力"这一动作：它把开源模型的安全治理从"事后过滤"前移到"训练阶段的能力抑制"，我国若要在开源生态上建立可信形象，这套做法提供了可复用的合规范式。同时也要清醒：2.8万亿参数意味着绝大多数中小开发者即使拿到权重也跑不动，最终仍会回到官方 API，生态红利未必人人均沾；真正的壁垒仍是算力与工具链，而不是权重本身。

DeepSeek V5 被曝将以昇腾 950 为核心训练算力，首次尝试"国芯训国模"

发布时间：2026-11-03 18:00（北京时间）　|　来源：科创板日报 / 财闻　|　阅读原文 ↗

11月3日，多名产业链人士向《科创板日报》与财闻证实，DeepSeek 下一代大模型 DeepSeek V5 计划采用华为昇腾950芯片作为核心训练算力，节奏指向明年落地。此前昇腾在 DeepSeek 模型中仅承担推理任务，V5 将是其首款原生依托昇腾开展训练的大模型。双方核心研发对接团队常驻杭州，已在 V4 阶段完成大量底层算子适配与定制开发；原先基于英伟达 CUDA 的算子链路已迁移至开源 Python 算子生态，无需从零重写底层代码。算力集群方面，DeepSeek 规划在乌兰察布建设大型智算中心部署昇腾950，预计明年建成投运。产业链人士同时确认，华为并未参与 DeepSeek 股权投资，双方仅停留在产品、算力与技术适配层面的商业合作。

▍价值点分析

这条消息的分量全在"预训练"三个字。推理验证的是"模型能不能跑"，预训练检验的是"模型能不能造"，后者对卡间互联、节点通信、并行效率、故障容错与软件栈成熟度的要求高一个量级。若 V5 跑通，将是国产芯片首次支撑顶尖大模型的完整训练链路，直接削弱"高端算力管制＝锁死中国前沿模型"这一假设，也会把全球算力竞争从单卡性能比拼推向系统生态比拼。风险同样明确：单卡显存小、集群稳定性、生态迁移成本仍是变量，乌兰察布基地尚在初期建设，实际节奏取决于工程落地而非意愿。这是最值得跟踪的一条技术主线。

腾讯混元 Hy4 preview 发布即全面开源，主打长程任务"跑得稳也用得起"

发布时间：2026-11-03 14:00（北京时间）　|　来源：中国经济网　|　阅读原文 ↗

11月3日开幕的2026年世界互联网大会"互联网之光"博览会上，腾讯展出了最新发布的混元 Hy4 preview 大模型。据现场介绍，该模型发布即全面开源，面向软件工程、科研攻关、智能办公等生产力场景，重点增强长程任务的理解、规划与验证能力，目标是让长程任务"跑得稳也用得起"。同场，蚂蚁灵波（LingBot）展示了智慧药房场景：机器人在80厘米宽的窄通道内可自主完成订单接收、智能分拣到商品交付的全流程；其具身原生跨本体基座模型开源9个月来下载量已突破220万次。本届峰会以"开源开放 共建共享——携手构建网络空间命运共同体"为主题，提升开源供给能力、繁荣开源生态成为主要议题。

▍价值点分析

国内大厂的开源策略正从"补生态"转向"抢标准"。混元选择在长程任务——也就是 Agent 最核心的短板——上做开源，实质是想让开发者把复杂工作流跑在自家底座上，从而在智能体时代占据入口。对我国的正面意义是开源供给持续增强，中小企业不必重复造轮子；隐忧在于开源模型已高度同质化，真正稀缺的是配套的推理加速库、微调框架与长期维护能力。这恰是海外 Hugging Face 生态的强项，也是我国开源最需要补的课——权重开放只是入场券，生态留存才是护城河。

谷歌提出"睡眠框架"：让大模型边睡边学，对抗灾难性遗忘

发布时间：2026-11-03 10:00（北京时间）　|　来源：前沿快讯（搜狐）　|　阅读原文 ↗

谷歌研究团队发布"睡眠框架"（Sleep Framework），模拟人类睡眠的记忆巩固机制，为大模型引入"清醒—睡眠"周期性运行模式：清醒阶段接收信息并暂存为短期记忆，睡眠阶段暂停处理新输入，通过记忆巩固与"梦境"自改进两个阶段，将短期上下文信息转化为长期参数记忆，同时避免覆盖原有知识。测试显示，该框架可将连续学习后旧任务准确率降幅减少超过60%，且无需重训旧数据即可保持能力稳定。研究团队称，这为大模型的终身持续学习提供了一条全新解决路径，相关思路可延伸至端侧模型的长期在线适应。

▍价值点分析

灾难性遗忘是大模型"持续进化"的根本障碍——每学新东西就可能丢掉旧能力，导致企业只能靠全量重训或外挂检索绕过去。若睡眠框架能工程化，意味着模型可以像人一样"边用边学"，而不必每次都重训，这对算力成本是数量级的节约。对我国而言，这条路线尤其值得跟进：在高端算力受限的条件下，"低成本持续学习"比"堆算力重训"更符合现实约束，也是国产模型实现弯道超车的少数可行技术方向之一。建议国内高校与头部实验室尽快复现，抢占这一方向的论文与标准先机。

AI 推理服务商 Fal 完成 13 亿美元融资，估值半年翻倍至 160 亿美元

发布时间：2026-11-04 04:10（北京时间）　|　来源：彭博社（网易转载）　|　阅读原文 ↗

据彭博社报道，总部位于旧金山的 AI 推理初创公司 Fal 完成13亿美元新一轮（F轮）融资，由 Bessemer Venture Partners 领投，英伟达、Sound Ventures、HOF Capital 与普信集团参投，估值由今年4月的80亿美元翻倍至160亿美元。加上此前由红杉资本领投的 E 轮，两轮合计融资16.5亿美元。Fal 主要为创作者与开发者托管并运行图像、视频、音频模型，客户大量依赖开源模型；其年化收入今年早些时候已突破8亿美元。提供同类服务的 Baseten、Fireworks AI 与 Modal 也在快速成长并以更高估值完成大额融资，但由于购买或租赁算力的成本高企，多家推理公司的毛利率仍明显偏薄。

▍价值点分析

推理赛道估值半年翻倍，说明产业共识已从"训模型"转向"卖推理"。英伟达直接参投推理聚合平台，是在锁定下游出货与生态入口——谁的推理平台最省单位 token 成本，谁就掌握开发者。对我国而言，这一模式值得警惕也值得借鉴：一方面，海外平台正把中国的开源模型（DeepSeek、Qwen、Kimi 等）托管变现，我国模型厂商并未分享这部分增值收益，等于用自己的成果喂养对手的生态；另一方面，国内推理算力平台仍高度分散，缺少统一的按 token 计价的公共底座，这是可以补的产业空白，也是智算中心从"卖机柜"升级为"卖服务"的关键一步。

Palantir 三季度营收同比增 96%，美国商业收入首次超过政府收入

发布时间：2026-11-03 13:00（北京时间）　|　来源：澎湃新闻　|　阅读原文 ↗

当地时间11月2日，Palantir 公布2026财年三季度财报：营收23.13亿美元，同比大增96%，为公司季度营收首次突破20亿美元；净利润11.28亿美元，同比增超一倍；调整后每股收益0.44美元，均超市场预期。最受关注的是美国商业收入同比增长148%至9.84亿美元，首次超过美国政府业务的9.53亿美元（同比增96%），过去两年其美国商业收入已增长逾5倍。公司上调全年营收指引至85.3亿美元左右，四季度指引26.5亿美元高于预期，但环比增速较上季放缓。CEO 卡普在致股东信中把增长归因于"主权 AI 运动"，并再次支持开放权重模型、批评闭源实验室索取数据主权。财报后股价仍下跌约3%。

▍价值点分析

Palantir 的商业化路径对我国 AI 厂商是最直接的参照：它的护城河不是模型，而是把 AI 嵌入政企的决策流程与数据底座，一旦进入就极难替换。美国商业收入反超政府收入，说明"AI＋行业流程"的付费意愿已真实形成，而非靠政策订单撑起来的虚假繁荣。对我国而言，国产大模型厂商普遍强于模型、弱于落地交付，缺少 Palantir 式的领域本体（Ontology）与工程化驻场团队。卡普"呼吁实验室国有化、支持开放权重"的表态虽是商业话术，却点出一个真问题：数据主权与模型控制权正在成为政企采购的核心条款。

2026年11月3日，据金融时报旗下 FT Technology News 报道，英伟达已要求数据中心客户降低对中国市场的算力敞口，核心约束是：单一数据中心向中国客户出售的算力不得超过其总量的49%。同日，政策评论者 Chris McGuire 在社交平台 X 上批评这一安排，认为既然受出口管制的芯片不能直接卖给中国企业，那么通过海外数据中心远程租用算力也不应被允许，合理阈值应是零。报道指出，这一约束针对的不是芯片出口许可，而是数据中心客户的算力销售结构——受影响的不仅是 GPU 整机与板卡，还包括 GPU 云、智算中心与第三方算力租赁等"以服务形式交付算力"的环节。

▍价值点分析

49% 这个数字的真正含义，是承认了高端算力可以绕过物理关境、以远程服务的形式跨境交付——管制边界因此从"芯片是否跨境"延伸到"算力服务是否跨境"。对我国 AI 企业，这意味着此前经第三国数据中心租卡训练的路径正在收窄，且合规审查会穿透到最终用户与实际用途，转售链条越长风险越不可控。应对上，短期需重新评估算力来源的合规风险与合同可执行性，避免训练任务中途被断供；中期则必须把训练负载迁移到国产算力，DeepSeek V5 选择昇腾950正是这一逻辑的直接注脚。这条线的后续演进，取决于美方是否把 49% 进一步压到零。
